
# Banking Fraud Detection System

## Project Overview
This project aims to develop a machine learning
system that identifies potentially fraudulent
credit card transactions.

## Objective
- Analyse financial transaction data.
- Identify patterns associated with fraud.
- Train machine learning classification models.
- Evaluate model performance.
- Predict potentially fraudulent transactions.

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- XGBoost
- Streamlit

## Project Status
Currently in development.
